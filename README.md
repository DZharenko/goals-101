# 101 цель — трекер целей (PWA + Яндекс.Диск)

Кроссплатформенное приложение (ПК + Android) для методики «101 цель».
Без своего сервера: данные — один файл `data.json` на вашем Яндекс.Диске,
код — статика (Яндекс.Диск «Опубликовать как сайт» или любой статический хостинг).

## Возможности (v0.1 — MVP)

- Цели по годам с полями из Excel: область, блок выполнения, приоритет, тип
  (количественная/качественная), количество, часы, стоимость, сложность, статус
- Подцели: прогресс по каждой подцели (книги) + общий прогресс цели
- Лог выполнения с датой, количеством, комментарием и часами
- «План на день»: разовые и еженедельные слоты расписания, редактируемые
- Тренировки с упражнениями (название, подходы, повторы, вес), связь с целью
- Челленджи: отметки по дням, текущая серия и рекорд
- Задачи вне 101 цели со сроками
- Итоги года: баллы (Σ весов выполненных) со шкалой из Excel
  (739→«Удовлетворительно» … 1478→«Ты бог»), % изначальных целей
  (60/70/80/90/100), разбивка по областям, сравнение по годам, часы
- История всех событий (events, append-only)
- Синхронизация через REST API Яндекс.Диска, offline-first (IndexedDB)
- Экспорт/импорт JSON как страховка

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ — готовая к публикации папка
```

## Публикация без сервера (2 способа)

1. **Яндекс.Диск**: создайте папку (например `Приложения/101цели`), положите туда
   содержимое `dist/`, ПКМ по папке → «Опубликовать как сайт». Откройте URL
   с любого устройства, на телефоне — «Добавить на главный экран».
2. **Фолбэк**: любой статический хостинг (GitHub Pages, Netlify Drop) —
   просто перетащите папку `dist/`. Данные всё равно хранятся на Яндекс.Диске.

Обновление приложения = замена файлов в папке (PWA подхватит новую версию).

## Подключение синхронизации (один раз)

1. Зайдите на [oauth.yandex.ru](https://oauth.yandex.ru) → «Зарегистрировать новое приложение».
2. Название: любое (например, «101 цель»). Платформы: **Веб-сервисы**.
3. Redirect URI: точный адрес, по которому открывается приложение
   (например, `https://ваш-логин-сайта.yandex.ru/`).
4. Доступы: **Яндекс Диск REST API** — чтение диска, запись на диск.
5. Нажмите «Создать» и скопируйте **ClientID**.
6. В приложении: вкладка «Синк» → вставьте ClientID → «Войти через Яндекс».

Токен хранится только в вашем браузере. Приложение пишет один файл:
`/101-goals/data.json` на вашем Диске.

## Перенос данных из Excel

```bash
node tools/migrate-excel.mjs "..\Цели - 2025.xlsm" 2025 > data-2025.json
```

Отчёт о миграции печатается в stderr (в файл `migration-report.txt`).
Затем в приложении: «Синк» → «Импорт JSON» → выберите `data-2025.json`.
Исходный Excel остаётся нетронутым бэкапом.

## Как работает синк

- Pull+merge при каждом открытии приложения и после правок (пауза 5 с)
- Конфликт двух устройств: побеждает более поздняя правка каждой записи
- Всё локально продублировано в браузере (IndexedDB) — облако недоступно,
  приложение продолжает работать офлайн
- Кнопка «Экспорт JSON» — ручная страховка в любой момент

## Ограничения (осознанные)

- На телефоне нет фоновой синхронизации — данные обновляются при открытии
- OAuth implicit-токен живёт ограниченное время — периодически потребуется
  повторный вход через кнопку «Войти через Яндекс»
- Если REST API Яндекса закрыт для браузеров (CORS) — используйте размещение
  через фолбэк-хостинг; если и это не поможет, потребуется обёртка Capacitor
